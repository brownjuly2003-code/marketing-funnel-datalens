# Контракт метрик

- Все времена переводятся в UTC. Пакет рассматривается целиком: расходы должны относиться к тому же наблюдаемому периоду. Демо охватывает события января; по дням/филиалам расходы не детализированы.
- Воронка — уникальные пользователи с упорядоченными `impression → click → install → registration → subscription`. Времена строго возрастают; отдельного ограничения длительности воронки нет.
- Каждая подписка атрибутируется отдельно. Рассматриваются только предшествующие касания того же user_id. Клики: окно 7×24 часа, левая граница включена. Если подходящих кликов нет, показы: окно 24 часа. Касания в тот же момент, что и подписка, исключены.
- `last_click`: последний допустимый клик; при отсутствии кликов — последний допустимый показ. При одинаковом времени касаний выбирается лексикографически больший event_id. Это техническое правило, не доказательство реального порядка.
- `linear`: одинаковый вес каждому допустимому касанию; несколько касаний канала суммируются. `time_decay`: вес `2 ** (-возраст_в_сутках)`, затем нормировка; период полураспада — сутки. Правило приоритета кликов действует для всех трёх моделей.
- Нет касаний — канал `unattributed`. Сумма весов на подписку равна 1; число конверсий канала может быть дробным.
- Выручка, себестоимость и расходы — целые копейки. Распределение денег: квота канала вниз, оставшиеся копейки по убыванию дробного остатка, при равенстве — по имени канала. Суммы сохраняются для каждой подписки и каждой модели. В `linear` квота и остаток считаются точно в целых числах: `divmod(сумма × касания канала, все касания)`; в `last_click` канал получает всю сумму. В `time_decay` квота — `сумма × вес` в числах с плавающей точкой, поэтому при математически равных остатках порядок может решить округление, а не имя канала.
- CPA = расходы / атрибутированные подписки; без подписок — `null`. Маржа после рекламы = выручка − себестоимость − расходы. Это упрощённая учебная маржа без налогов, возвратов и постоянных затрат. У `unattributed` расходов нет: при положительном числе подписок без атрибуции его CPA = 0 — техническое значение, не бесплатное привлечение; без таких подписок CPA равен `null`, как у любого канала.
