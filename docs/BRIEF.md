# P16 — постановка

## Что обещано (своими словами)

Освоить маркетинговую аналитику на учебном стенде с синтетическими событиями и расходами по
каналам: воронка «показ → клик → установка → регистрация → подписка», сравнение моделей
атрибуции (last click, linear, time decay с окном post-view), CPA и маржа по каналам с
проверкой агрегатов по SQL. Подготовить витрину в ClickHouse и дашборд в open-source DataLens
в Docker с подключением к ClickHouse из AgentFlow и селекторами по филиалу и периоду.

## Итог одной фразой

На 488 синтетических событиях 120 пользователей (seed) я собираю последовательную воронку
120 → 99 → 75 → 58 → 37, сравниваю три модели атрибуции подписок, считаю CPA и маржу по
каналам в копейках и сверяю результаты Python, SQLite и сервера ClickHouse.

Каждая часть фразы подтверждена в [README](../README.md): «Измеренный результат» и таблица
«Утверждение → доказательство».

## Этап

Сохранённый снимок загружается в ClickHouse. SQL распределяет веса и копейки по каждой подписке, затем собирает канальную витрину. [Запуск и схема таблиц](../README.md#витрина-в-clickhouse)

## Границы

Для фильтров по филиалу и периоду подготовлен [запрос к снимку заказов AgentFlow](../sql/datalens/agentflow_orders_daily.sql). Предстоит подключить работающую витрину и проверить датасеты, чарты и селекторы в DataLens.
